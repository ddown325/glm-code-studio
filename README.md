# glm-code-studio ⚡

**GLM Code Studio** — a single-file AI coding studio that builds games and web apps with **GLM 5.3** (via OpenRouter / Z.AI / DeepSeek / OpenAI-compatible APIs).

## Run it
- Open `glm-code-studio.html` (or [`index.html`](./index.html)) in any modern browser — that's it, no build step, no dependencies.
- First run: click **Settings ⚙**, paste your API key (stored only in your browser's localStorage, never in the file).
- Describe a game or tap a preset (Snake, Breakout, Space shooter, Platformer, 2048, To-do) — the code streams in and runs live in the Preview tab.
- Iterate by chatting ("add power-ups", "make it harder"), edit the code by hand, then **Push to GitHub** from inside the app to publish your game.

## Features
- 🤖 Agent mode: build plan → full implementation → self-review
- ▶ Live sandboxed preview + code editor with line numbers
- 🐙 GitHub integration: create repos, push apps, one-click GitHub Pages setup
- 🔑 Multi-provider settings (OpenRouter · Z.AI · DeepSeek · OpenAI · custom), key stays in localStorage

## Files
- `glm-code-studio.html` — the app
- `index.html` — same file, served at the repo root for GitHub Pages

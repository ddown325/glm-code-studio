🐙 GitHub

Connect your GitHub account

Push the apps you build straight to a GitHub repository — then host them free with GitHub Pages. Everything runs in your browser; the token is stored only in localStorage.
Create a token ↗
Token scopes needed: fine-grained → Repository: Read & Write, Metadata: Read (classic → repo + workflow). Keep the shortest expiry you like; you can revoke it any time on GitHub.

🤖 Let the AI do the Git work

Tip: in Agent mode you can just chat “push this to a new repo called my-games and enable GitHub Pages” — the studio's agent uses the GitHub API on its own to create repos, write files and push.

Push current app

Commit the file from the Code tab (or the live preview) to one of your repositories. Uses the GitHub Contents API — no git command line needed.

🌍 Free hosting with GitHub Pages

After pushing index.html to a public repo, turn on Pages once and every future push auto-deploys. The button below opens the exact settings page.
In the GitHub UI: Settings → Pages → Branch: main / (root) → Save. Your game goes live at https://<user>.github.io/<repo>/ within a minute.
